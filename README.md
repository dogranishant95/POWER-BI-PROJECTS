## 🚗 2. Uber Rides Analytics Dashboard

### 📌 Project Overview
Uber ride bookings data ka ek detailed analytical dashboard jo ride trends, peak hours, cancellations, aur revenue patterns ko analyse karta hai.

### 📸 Dashboard Preview
*(Agar aapke paas Uber dashboard ka screenshot hai toh repo mein upload karke `![Uber Overview](uber_screenshot.png)` yahan add kar sakte hain)*

### 🛠️ Key Features & Tools
- **Ride Patterns:** Daily aur monthly ride volume analysis.
- **Booking Status:** Completed, cancelled, aur customer retention breakdown.
- **Revenue & Distance:** Total earnings, average fare, aur distance covered metrics.
- **Tools Used:** Power BI Desktop, DAX Calculations, Data Modeling.
- **Files:** `uber dashboard.pbix`, `uber.xlsx`
